调色，先懂「控制什么」

调色不是套一个滤镜就完事。真正理解下面这些工具，你就能自由地还原/塑造一张图的气质。

🌡️ 白平衡 / 色温色调

色温让画面整体偏暖(橙)或偏冷(蓝)；色调让画面偏洋红或偏绿。

  • 偏了白平衡，皮肤会发黄/发红——先校正再谈风格。
  • 想干净：降一点点黄(反方向调)，人会显得更通透。

🔆 曝光 / 对比度 / 高光阴影

决定画面的「明暗结构」。控制整体的明和暗，以及暗部是否「发灰」。

  • 日系常用整体提亮 + 压缩对比 + 提升暗部(发灰)。
  • 港风/电影感常用增强对比 + 压暗阴影制造情绪。

🎨 饱和度 / HSL

饱和度控制整体颜色浓淡；HSL 能单独控制某一种颜色的色相/饱和度/明度。

  • 调橙色：影响皮肤/肤色。
  • 调青色/蓝色：影响天空、冷调氛围。
  • 调绿色：影响植物、草地(常降饱和显高级)。

📈 曲线 (Curves)

最强大、最自由的工具。横轴是输入亮度，纵轴是输出亮度，可对 RGB 整体或 R/G/B 单通道分别拉。

  • S 形：增强对比，最常见的电影感起点。
  • 抬黑点：左边端点往上抬 = 暗部发灰(胶片感)。
  • 单通道：蓝通道高光提亮=冷高光；红通道暗部下压=青阴影。

⚖️ 色彩平衡 / 分离色调

给「阴影 / 中间调 / 高光」三个区域分别染上颜色。

  • 分离色调：阴影加青 + 高光加橙 = 经典的「青橙」电影配方。
  • 阴影加蓝 + 高光加黄 = 日系清凉感。

🩸 色阶 / 黑白场

用 输入/输出 的黑白点 + 中间灰 控制曝光范围，修偏色的第一站。

  • 发现灰蒙蒙没层次：定一下黑白场，立刻通透。
  • 偏色的图，先在黑白场里平衡，再进曲线。

💡 修图小口诀

  • 先定白平衡 → 再修曝光 → 然后调肤色/局部 → 最后整体风格。
  • 肤色是底线：先把人体肤色调自然，再谈风格。
  • 风格是「锦上添花」，别用风格掩盖基本功问题。
  • 少即是多：多数好看的照片只改了两三个关键值。
